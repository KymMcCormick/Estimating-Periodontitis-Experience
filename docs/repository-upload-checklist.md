# Repository upload checklist

Before making the repository public:

- [ ] Replace `YOUR-USERNAME` in `CITATION.cff`.
- [ ] Replace `your.email@example.com` in `DESCRIPTION`.
- [ ] Confirm whether MIT licensing is appropriate for your institution and collaborators.
- [ ] Confirm that no raw NHANES files or generated analytic datasets are committed.
- [ ] Run the pipeline locally from a clean R session.
- [ ] Update this checklist after the first successful end-to-end run.
