# data/raw

Place NHANES source `.xpt` files here.

The current first-iteration pipeline expects:

- `DEMO_F.xpt`, `DEMO_G.xpt`, `DEMO_H.xpt`
- `GHB_F.xpt`, `GHB_G.xpt`, `GHB_H.xpt`
- `OHXPER_F.xpt`, `OHXPER_G.xpt`, `OHXPER_H.xpt`

Raw NHANES files are deliberately ignored by Git. Keep this directory local.
